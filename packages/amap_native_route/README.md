# amap_native_route

Driving, walking, cycling and transit route planning for the
[`amap_native`](https://github.com/SakuraCake/amap_native) federated Flutter
plugins.

Use `AmapRouteClient`. Routes are provided by the AMap search service, so the
Android Key must have the corresponding service enabled.

Android requires `amap_native_android`; iOS currently throws
`AmapUnsupportedError`.
